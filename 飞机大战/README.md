# 飞机大战 ✈️

经典飞机大战射击游戏的HTML5版本，使用纯前端技术实现。

## 游戏截图

![飞机大战](screenshot.png)

## 特性

- 🎮 简单易上手的操作方式
- 💥 炫酷的爆炸粒子特效
- 🚀 3种不同类型的敌机
- 🎁 道具系统（生命恢复、火力增强）
- 📈 难度递增系统
- 📱 支持鼠标和触摸操作

## 快速开始

1. 克隆或下载本项目
```bash
git clone https://github.com/yourusername/airplane-war.git
```

2. 直接在浏览器中打开 `index.html` 即可开始游戏

或者使用本地服务器：
```bash
# 使用 Python
python -m http.server 8080

# 使用 Node.js
npx serve
```

## 游戏操作

| 操作 | 说明 |
|------|------|
| 鼠标移动 | 控制飞机左右移动 |
| 触摸滑动 | 移动设备控制飞机 |
| 空格键 | 暂停/继续游戏 |

## 游戏玩法

1. 飞机自动射击，无需手动操作
2. 击毁敌机获得分数
3. 躲避敌机和敌机子弹
4. 收集道具增强能力
5. 生命值归零时游戏结束

## 敌机类型

| 敌机 | 生命 | 分数 | 特点 |
|------|------|------|------|
| 小型敌机 | 1 | 100 | 速度快，数量多 |
| 中型敌机 | 3 | 300 | 会发射子弹 |
| 大型敌机 | 6 | 500 | 高血量，强力射击 |

## 道具说明

- ❤️ **生命道具**: 恢复1点生命值
- ⚡ **火力道具**: 提升射击频率

## 素材生成

打开 `assets.html` 可以：

- 下载单个PNG图片
- 一键下载全部素材

## 技术实现

- **渲染**: HTML5 Canvas 2D
- **动画**: requestAnimationFrame
- **特效**: 粒子系统
- **兼容**: 桌面端 + 移动端
